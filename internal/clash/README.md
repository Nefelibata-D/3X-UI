# Clash 进程内扩展

## 当前代码边界

- `models.go`：持久化数据模型；`catalog.go`：官方数据的项目只读视图；`weights.go` / `ratio.go`：权重解析与归一化。
- `quota.go`：额度校验与保存；`overview.go`：管理端查询视图；`delivery_plan.go`：下发计划；`policy_operations.go`：重置与同步入口。网关与通行密钥分别保持在 `gateway/`、`passkey/`。
- `remote.go`：仅解析节点身份并调用项目策略接口。`internal/web/runtime/project_request.go` 为官方 Remote 提供窄适配，复用认证、URL、超时、私网策略、请求完整性及响应解析。官方请求保留 64 MiB 上限；项目请求保持 8 MiB 上限并禁止重定向。
- `internal/sub/clash_project.go`：项目订阅目录、预览和发布编排；官方 `clash_service.go` 继续负责授权和协议代理生成，仅接入来源记录与项目渲染。
- `internal/web/clash.go`：项目启动钩子，`web.go` 保留生命周期调用。节点删除定制按用户要求保留，不改变此次重构的业务行为。
- 前端共享编辑器在 `components/clash/subscription/`，校验与引用处理在 `lib/clash/subscription/`；schema 在 `schemas/clash/`，资源查询和 mutation 在 `api/queries/`。不从通用组件反向引用页面。

## 功能契约与历史记录

负载均衡为每个节点配置独立总额度 capacityBytes、默认权重和每月重置日/时间。客户端在“负载均衡”标签为每个已关联节点分配额度、继承或覆盖权重；分配从对应节点额度池扣减，权重不由额度推导。节点总额度 0 表示不限；有限节点要求明确的正数分配，并校验该节点所有客户端分配合计不超总额度。修改分配按新值替换旧值，保存串行化，避免并发超分。新增关联但未分配额度的有限节点策略拒绝准入。

每个客户端 × 节点拥有独立下发策略、账本和重置操作。限额 0 表示无限：继续经过网关计量、回报，不触发额度停用。有限改为无限会解除宽限/额度停用，但保留当前用量。每个节点按主控时区独立配置每月 1–31 日和 00:00–23:59，短月取月末。客户端 resetMode=node 时跟随各节点周期；manual 时仅手动重置。重置只清零该客户端在该节点的用量，保留分配额度，不退回或重复扣减配置额度池，也不修改官方总流量与有效期。修改周期保留用量；账本记录周期配置，防止配置保存与账本刷新之间重启沿用旧周期。客户端列表和标签按节点显示用量及各自限额，不将官方历史合计流量按比例摊分。缺失回报显示待回报，远端异常显示错误，不伪造 0 用量。

存储复用 clash_node_budgets 表，新增 capacity_bytes 和 quota_reset_* 保存节点配置；历史 budget_bytes 列不恢复为权威来源，也不自动分给客户端。clash_client_ratios 增加 limits_json 保存客户端的节点额度，未配置项为 0。既有显式自定义权重保留。clash_deliveries / clash_applied_policies 的账本按 clientId 与节点身份分开。共享入站通过 Xray 的 inboundTag + user 路由隔离：UUID 认证继续由 Xray 负责，认证后的官方 email 标识映射到客户端策略，不复制凭据。

管理 API /panel/api/clash/：overview；POST weights（items: [{nodeKey, defaultWeight, capacityBytes, resetSchedule: {day, minute, disabled:false}}]）；GET clients/:id 返回节点配置与账本；POST clients/:id/ratio 一次保存 {mode, weights, limits, resetMode}，limits 是 nodeKey 到字节上限的映射；policies/reset 重置一个节点/客户端账本；sync、policy/apply、policy/report。前端显式使用 application/json。全局 budgets 写接口已删除。

网关位于 gateway/，面板进程内 TCP SOCKS 数据面，不是 node-agent。子面板必须部署带扩展的 3x-ui。预算达到后进入宽限，服务端继续计量并允许新连接，宽限行为由客户端主动限制；时间或额外流量先到后，仅终止该用户的网关连接并拒绝新连接，不关闭共享代理入站。保留版本屏障、幂等重置和持久化错误传播。UDP 不支持。

客户端接口 GET <basePath>/v1/nodes/:node/status 使用官方客户端 UUID 和出口面板 GUID；200/409/403 表示正常/宽限/停用；未应用或无法确认回报为 503。Mihomo 无需修改；weighted-sticky 首次绑定按权重抽选、随后保持黏性，正式订阅消费仍属下一阶段。

项目 UI 直接中文，官方国际化不改。项目组件独立文件，复用官方样式和请求工具。客户端列表接入独立节点流量组件，流量条利用剩余宽度，移除重复的“剩余”列，“实时速度”说明其为观测速率；官方账户总额度和基础 API 含义不改。关联变更后刷新项目缓存，节点报告每 10 秒刷新。

验证边界：此前跨容器 TCP 下发、计量、停用、重置和主控回报曾通过；不能替代本轮客户端节点限额与无限额计量的回归。新定向验收：同一客户端两个节点不同限额；两个客户端同一节点不同限额（共享入站）；0 无限仍计量；停用后改 0 恢复且不清零；页面保存回读及独立流量显示。测试仍交 DS，项目测试保持未跟踪。

官方客户端 TotalGB 是整个客户端的总流量上限；设为有限值时，每个已关联节点额度也必须有限，且额度合计不得超过 TotalGB。TotalGB 为 0（无限）时，节点额度可以有限或无限。单节点分配仍不得超过该节点可分配额度。总流量周期重置时同步清零该客户端全部节点账本，并暂停节点独立周期；总流量重置设为 never 时，节点账本才按节点各自周期重置。官方服务仍是 TotalGB 的唯一写入方。

列表 ID 接线：官方 ClientSlim / toClientSlim 增加官方记录 id；列表流量组件按此 ID 查询，不能将精简列表缺少 ID 误报为未关联节点。标签分配方式使用 Select，继承时隐藏权重输入，仅保留最终比例；0 无限含义通过问号 Tooltip 显示。

节点删除：沿用官方删除 API，但语义为解除主控管理。NodeService.Delete 在事务中清理主控入站副本、客户端关联、Host、订阅组选项、节点流量基线及项目权重/额度/下发记录；保留客户端账户、累计流量、其他节点及远端配置。不调用远端 DelInbound。同步任务与删除互斥，迟到快照遇到已删除节点直接退出。前端确认框说明边界，成功后刷新相关查询。上游接线位于 service/node.go、service/inbound_node.go、job/node_traffic_sync_job.go，清理实现分别放 service/node_detach.go 和 clash/node_removal.go。

## 客户端订阅

客户端列表操作栏和移动端菜单提供“Clash 订阅”。绑定保存在 clash_subscription_bindings，以官方 SubID 为主键，同一订阅身份共享配置；templateId=0 解除绑定。管理接口为 GET/POST /panel/api/clash/clients/:id/subscription，复用管理员认证与 CSRF。

模板保持为权威基础，只存客户端差异。路由、规则集和节点组通过右侧底部“模板 / 自定义”切换查看；模板项可禁用或复制覆盖，复制后自动进入自定义；禁用项红底灰字，覆盖项灰字。路由按类型和完整匹配内容识别，忽略目标及末尾参数，覆盖保留原位置；新增项放在最终 MATCH 前。规则集和节点组按名称覆盖。删除客户端覆盖项恢复模板继承，同时解除该项的显式禁用。负载均衡复用模板编辑器；修改其网站黑名单时保存客户端黑名单配置。

节点注入支持全部已分配节点动态继承，或显式选取已分配节点。官方转换器生成凭据和代理，窄接线记录其实际所属节点，在代理名称去重后交给项目渲染；不复制协议转换逻辑，不新增凭据权威源。模板静态独立代理凭据拒绝绑定，空注入组、未知引用、循环组依赖在校验中报错。被绑定模板禁止删除。链接沿用官方 Clash 订阅地址。

管理员订阅预览通过 subscription/proxies 返回官方 SubClashService 生成的完整代理配置及 nodeKey、inboundKey、inboundName、hostOverride 来源。新绑定的 groups[].nodes 保存 inbound:<官方入站 ID>，按入站选择并保留该入站的主机覆盖变体；旧 local/node:<ID> 绑定保持按服务器展开，编辑器将可解析的旧选择展开为入站选择，未解析项保留以供修正。正式发布和草稿校验共用相同选择规则，保存时核验客户端入站授权。前端不另行实现协议转换，不改写官方代理名或持久化生成凭据，该接口仍使用管理员 session/CSRF 路由。

订阅 proxies 保留模板显式定义，只追加用户选择注入的官方生成节点（以及明确选择的链式节点）；未选择不注入。重名由发布校验拒绝，不覆盖模板代理。定向检查 TestSubscriptionPreservesTemplateAndSelectedProxies 覆盖未选、单选、全选。

本轮服务端重置审查：官方单用户重置已有项目接线，补齐批量重置、入站下全部用户重置和全局重置的节点账本通知。官方客户端周期任务走单用户重置，官方入站周期任务走入站下全部用户重置；两者均通知扩展。节点自身周期由网关按配置独立结算。重置请求持久化为待同步状态，节点不可达时保留请求，成功应用后确认；版本屏障避免同一重置重放清掉新流量。节点 capacityBytes 只约束额度分配，不依据节点累计用量封禁所有用户；官方限额与客户端 disabled 查询策略不变。
